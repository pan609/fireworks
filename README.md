# 跨年烟花秀

用 HTML 和 JavaScript 做的跨年烟花页面：11 种花型、合成音效、祝福语、跨年倒计时，背景是 6 个地标的实拍夜景。

直接用浏览器打开 `index.html` 即可。想要背景音乐，把歌曲改名为 `music.mp3` 放在同一目录，或在页面左上角控制台里选择本地音乐文件。
